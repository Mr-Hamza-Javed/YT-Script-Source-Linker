Source Linker

AI Visual-Guide output me sources ko automatically link karein — flexible, safe aur fully validated.

1 Input

Optional: Source list alag se paste karein (override)

Agar app aap ki source list khud detect na kar paaye, to sirf source list yahan paste karein. Yeh diya gaya ho to map isi se banega.

2 Settings

Link Only [12] → [[12]](url) Sirf number clickable banega.
Full Source [12] → [Title](url) Poora title + link replace hoga.

Tip: Full mode me jab aik jagah kayi sources aayein to Before/After/Join se clutter control karein (e.g. Before (, After )).
